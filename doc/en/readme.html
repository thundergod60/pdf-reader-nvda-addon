NVDA PDF Reader Add-on

Overview

The PDF Reader add-on for NVDA (NonVisual Desktop Access) provides accessible PDF reading capabilities for blind and visually impaired users. This add-on enables users to open PDF files, extract text content, and navigate through pages efficiently using keyboard shortcuts and an intuitive interface.

Features

  • PDF Import: Open and process PDF files through a simple file dialog
  • Text Extraction: Automatically extract text from PDF pages for screen reader access
  • Page Navigation: Navigate through PDF pages using previous/next buttons or keyboard shortcuts
  • Quick Page Access: Jump to specific pages using a dropdown selector
  • Accessible Interface: Fully accessible dialog boxes designed for screen reader users
  • Keyboard Shortcuts: Comprehensive keyboard support for all functions

Installation

  1. Download the latest version of the PDF Reader add-on
  2. Open NVDA and navigate to Tools > Manage Add-ons
  3. Click "Install" and select the downloaded add-on file
  4. Restart NVDA when prompted

Usage

Opening the PDF Reader

Press NVDA+Alt+P to open the main PDF Reader dialog.

Main Dialog Options

  • Import PDF: Browse and select a PDF file to open
  • About: Learn more about the add-on and access additional resources
  • Help: View step-by-step instructions for using the add-on
  • Close: Exit the PDF Reader

PDF Navigation Panel

Once a PDF is loaded, you can:

  • Use Alt+P for previous page
  • Use Alt+N for next page
  • Select a specific page from the "Go to" dropdown
  • View total pages and current page information in the status display
  • Navigate through extracted text using standard text navigation keys

Telegram Channel

The add-on provides access to a Telegram channel with additional resources and support for blind and visually impaired users. Access this through the About dialog.

System Requirements

  • NVDA 2019.3 or later
  • Windows 7 or later
  • PyMuPDF library (included in add-on)
